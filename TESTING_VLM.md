# Как протестировать улучшенный VLM анализатор

## Быстрый тест

1. **Запустите приложение:**
   ```bash
   docker-compose up -d
   ```
   или используйте Docker образ:
   ```bash
   docker run -d -p 5000:5000 galanovaxxx/cloring-web:latest
   ```

2. **Откройте браузер:**
   ```
   http://localhost:5000
   ```

3. **Зарегистрируйтесь / Войдите**

4. **Загрузите фото одежды:**
   - Перейдите в раздел "Загрузить одежду"
   - Выберите любое фото одежды (футболка, платье, джинсы и т.д.)
   - Нажмите "Загрузить"

5. **Наблюдайте результат:**
   - При первой загрузке модель скачается (~900 МБ, займет 1-2 минуты)
   - После этого вы увидите автоматически заполненные поля:
     - **Название** - полное название на русском (например, "Красное платье")
     - **Цвет** - цвет на русском (например, "Красный")
     - **Материал** - материал на русском (например, "Хлопок")
     - **Описание** - детальное описание на русском

## Что проверить

### Проверка русского языка:
- ✅ Все поля заполнены **на русском языке**
- ✅ Описание **естественное и читаемое**
- ✅ Цвет указан **по-русски** (Красный, Синий, Зеленый)
- ✅ Материал указан **по-русски** (Хлопок, Деним, Кожа)

### Проверка точности:
- ✅ Правильно определена **категория** (футболка, платье, джинсы)
- ✅ Правильно определен **цвет** (основной цвет одежды)
- ✅ Описание **соответствует** изображению

### Примеры для тестирования:

**Футболка:**
- Ожидаемый результат:
  - Название: "Синяя футболка" (или другой цвет)
  - Цвет: "Синий"
  - Категория: t-shirt
  - Описание: "Женщина в синей футболке..." (или подобное)

**Платье:**
- Ожидаемый результат:
  - Название: "Красное платье"
  - Цвет: "Красный"
  - Категория: dress
  - Описание: "Элегантное красное платье..."

**Джинсы:**
- Ожидаемый результат:
  - Название: "Синие джинсы"
  - Цвет: "Синий"
  - Материал: "Деним"
  - Категория: jeans
  - Описание: "Синие джинсовые брюки..."

## Логи для отладки

Если нужно увидеть, как работает анализ, проверьте логи Docker:

```bash
docker-compose logs -f
```

Вы увидите:
```
BLIP caption (general): a woman wearing a red dress
BLIP caption (detailed): a detailed red dress with long sleeves and buttons
BLIP caption (color): red dress
Parsed caption data: {'clothes_category': 'dress', 'clothes_color': 'Красный', ...}
```

## Известные особенности

1. **Первая загрузка** - модель BLIP загружается при первом анализе (~900 МБ, 1-2 минуты)
2. **Последующие анализы** - работают быстро (~2-3 секунды)
3. **Бренд** - пока не определяется автоматически (поле пустое)
4. **Английские категории** - категории остаются на английском (jeans, dress) для внутреннего использования, но название генерируется на русском

## Возможные проблемы и решения

**Проблема:** Поля не заполняются автоматически
**Решение:** Проверьте логи - возможно, модель еще загружается

**Проблема:** Описание частично на английском
**Решение:** Это нормально для некоторых редких слов - словарь можно расширить

**Проблема:** Неправильный цвет
**Решение:** Модель может ошибаться на сложных изображениях - можно отредактировать вручную

## Обратная связь

Если вы заметили, что какие-то слова не переводятся или переводятся неправильно, их можно добавить в словарь в файле `src/vlm_analyzer.py` в методе `_translate_description()`.
